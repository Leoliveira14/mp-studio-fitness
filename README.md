# MP Studio Fitness — site institucional

Site de apresentação do **MP Studio Fitness**, estúdio de treino personalizado na Vila Regente Feijó, São Paulo.

🔗 **Online:** https://mpstudiofitness.netlify.app

## Sobre
Página única, responsiva, com apresentação do estúdio, serviços, contactos e ligação direta ao WhatsApp. Todo o site está num único ficheiro `index.html`, com estilos, scripts e imagens incluídos, por isso abre sem instalar nada.

## Tecnologias
HTML5 · CSS3 · JavaScript · SEO (meta tags e Open Graph) · Netlify

## Como abrir
Abra `index.html` no navegador. Para publicar, arraste a pasta para https://app.netlify.com/drop.
